Aplicación de asignación de turnos, horarios y cuadrantes para patrullaje de seguridad comunitaria (específicamente la comuna de La Cisterna). La idea es reemplazar el registro manual y a papel.
Usuario: Jefe operativo
Ramo: Ingeniería de software - UDP
Grupo: 7

Funcionalidades: 
Registro del personal (Nombre, Turno, puesto (patrullero, radio operador o jefe de turno)
Generación de mallas mensuales compatibles con el Art. 38 código del trabajo y turno 4 x 3
Planificación 24/7
Asignación de cuadrantes (6 cuadrantes + feria)
Asignación de modalidades (Moto, Móvil, Bici, Infanteria)
Registro de vacaciones y licencias médicas
Edición manual
Asignación de Horas extras diurnas y nocturnas
Exportación de la malla a Excel

Requisitos:
Python 3.10 o superior
para ejecutar: pip install -r requirements.txt
